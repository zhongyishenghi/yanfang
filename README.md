# 易圣验方

一个不用联网的中医方剂查询工具。2086 首方，手机、电脑上都能用，随时查。

四种查法，想到哪个用哪个：

- **方名** — `六味地黄丸`，懒得打汉字就打拼音 `liuwei`，或首字母 `lw`
- **医家** — `刘渡舟`，看他名下都有哪些方
- **病名** — `肝硬化`、`头痛`，按病找方
- **药味** — `柴胡 黄芩`，中间空格分开，只出同时含这两味的方

不用注册，不用联网，不记录你搜过什么。数据全在本地，飞行模式照样用。

## 数据是什么

- **805 首验秘方** — 逐页转录自《首批国家级名老中医效验秘方精选》正编、续集等文献
- **1281 首药典方** — 取自《中华人民共和国药典》2025 年版的成方制剂与单味制剂

每首只留五样：方名、组成用量、功效、主治、用法。方解、按语、病例这类议论不进库——要的是一张能横向比较的表，不是电子书。

每首都标了出处：验秘方具体到书页，药典方具体到词条号，拿原书一对就知道有没有抄错。

## 怎么用

**安卓手机、平板**：到 [Releases](../../releases/latest) 下载 `yanfang-v1.0.8.apk`，点开安装。系统提示「禁止安装未知来源应用」时允许这一次即可，装好后桌面出现「易圣验方」，不用联网。

> 装过 1.0.7 及更早版本的，要先卸载再装这一版——v1.0.8 换了签名证书，系统不允许覆盖安装。之后的版本可以正常覆盖。

**电脑（Windows / macOS / Linux）**：到 [Releases](../../releases/latest) 下载 `yanfang-v1.0.8-web.zip`，解压后第一层就是 `index.html`，双击用浏览器打开。不用安装，也不用在子目录里翻。

> Release 页面上的 `Source code (zip/tar.gz)` 是给开发者的源代码，解压出来是整套工程，别下那个。

想自己从源码出包：`node tools/build-offline.mjs && cd app && npx cap sync android && cd android && ./gradlew.bat assembleRelease`（需 JDK 21、Android SDK 35，签名证书自备）。

## 几句实话

这是文献整理，供查阅参考，不是看病用的。方子对不对症要请医生判断，别自己抓药。

药典方的克数是制丸的投料量（比如配一千丸的总量），不是一次吃多少，实际服法看「用法与用量」那一栏。

少数辨认存疑的字，数据里标了校记，一并留着，不替原文做主。
